# Eid Mubark Wish Card

Single-page HTML Eid greeting card for viewing and customizing in a browser.

## Repository guide

### Contents

- [eid_mubarak_greeting.html](eid_mubarak_greeting.html)

### Getting started

```bash
git clone https://github.com/Raimal-Raja/Eid_Mubark_Wish_Card.git
cd Eid_Mubark_Wish_Card
```

Open eid_mubarak_greeting.html in a browser and edit its text or styles to customize the card.
